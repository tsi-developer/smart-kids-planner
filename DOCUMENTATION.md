# Smart Kids Daily Planner — Documentation

## Overview
Smart Kids Daily Planner is a full‑stack project that allows parents to manage their children's daily routines. It includes a planner, child management, and email notifications.

## Frontend
- Planner form
- Children form
- Navigation (sidebar + bottom nav)
- Search bar
- Responsive UI
- Category cards

## Backend
- Node.js + Express server
- Task API
- Children API
- Email API
- Nodemailer integration

## Email System
- Sends email notifications to parents
- Uses Mailtrap SMTP for testing
- Triggered when a new task is added

## API Testing
- Postman used for all endpoints
- Email sending verified
- JSON responses validated

## Deployment
Frontend: Vercel  
Backend: Render  

## How to Run Locally
1. Install Node.js  
2. Run `npm install`  
3. Start server: `node server.js`  
4. Open `index.html`  

## Conclusion
The project meets all final deliverables: functional frontend, backend email logic, and full documentation.
